ส่วนที่ 2 · การคิดแบบโปรแกรมเมอร์

🧭 การเขียนโปรแกรม และ Flowchart

การเขียนโปรแกรม (Coding) คือการสร้างชุดคำสั่งให้คอมพิวเตอร์ทำงานทีละขั้นตอน ด้วยภาษาที่คอมพิวเตอร์เข้าใจ เช่น Python เหมือนการสอนคอมพิวเตอร์ให้ทำสิ่งที่เราต้องการ ก่อนเขียนโค้ด โปรแกรมเมอร์มักวาด Flowchart คือแผนภาพลำดับขั้นตอนที่ใช้สัญลักษณ์และลูกศรเชื่อมต่อกัน

ประโยชน์ของ Flowchart

  • เห็นภาพรวมของกระบวนการ
  • เข้าใจง่าย สื่อสารกับผู้อื่นได้
  • หาจุดที่ต้องปรับปรุงได้
  • ใช้เป็นแนวทางตอนเขียนโค้ด

หลักการสร้าง 5 ข้อ

  1. มีจุดเริ่มต้นและสิ้นสุดชัดเจน
  2. ทิศทางการไหลชัดเจน (บนลงล่าง ซ้ายไปขวา)
  3. ใช้สัญลักษณ์ถูกต้อง
  4. ข้อความกระชับ ชัดเจน
  5. มีเส้นทางครบทุกกรณี

เครื่องมือวาด: PowerPoint, Google Slides, draw.io หรือวาดบนกระดาษแล้วถ่ายรูป

สัญลักษณ์พื้นฐาน

🔷 สัญลักษณ์ที่ใช้บ่อย 6 แบบ

Terminal · จุดเริ่มต้น / สิ้นสุด
Input / Output · รับข้อมูล หรือแสดงผล
Process · ประมวลผล คำนวณ กำหนดค่า
Decision · ตัดสินใจ มีทางออก ใช่/ไม่ใช่
Flow line · ลูกศรบอกทิศทาง
Connector · จุดเชื่อมต่อเมื่อแผนภาพยาวข้ามหน้า
ตัวอย่าง · Flowchart ที่มีการตัดสินใจ

🔐 การเข้าสู่ระบบ (Login)

รูปข้าวหลามตัด (Decision) แตกทางออกเป็น 2 ทาง ถ้า ไม่ใช่ ลูกศรวนกลับไปให้กรอกใหม่ ถ้า ใช่ ไปต่อ

⚠️ ทุกจุดตัดสินใจต้องมีเส้นทางครบทั้ง “ใช่” และ “ไม่ใช่” (หลักการข้อ 5) โค้ดของ Flowchart แบบนี้ใช้ if / else ซึ่งจะได้เรียนในครั้งที่ 2
กิจกรรม

🤝 กิจกรรมจับคู่ ⏱ 15 นาที

จับคู่กับเพื่อน วาด Flowchart การรับออเดอร์ผักของนำชัยฟาร์ม ตั้งแต่ลูกค้าสั่งจนส่งของ

  1. ลูกค้าแจ้งรายการผักและจำนวนที่ต้องการ
  2. พนักงานตรวจสอบผักในสต็อก
  3. จุดตัดสินใจ: ผักในสต็อกพอหรือไม่ ถ้า ไม่พอ แจ้งลูกค้าและเสนอวันส่งใหม่ ถ้าลูกค้าไม่ตกลงให้ยกเลิกออเดอร์ ถ้า พอ ไปขั้นต่อไป
  4. แพ็กผักลงลัง ออกใบส่งของ และจัดส่งให้ลูกค้า
  5. แลก Flowchart กับคู่ข้าง ๆ ตรวจตามหลักการ 5 ข้อ โดยเฉพาะว่าทุกจุดตัดสินใจมีเส้นทางครบทั้ง “ใช่” และ “ไม่ใช่” และทุกเส้นทางไปถึงจุดสิ้นสุด
  6. บันทึก Flowchart เป็นไฟล์รูปหรือ PDF (วาดด้วย draw.io, PowerPoint, Google Slides หรือวาดบนกระดาษแล้วถ่ายรูปให้ชัด) แล้วส่งผ่าน Google Form ด้านล่าง

🖨️ แสดงผลด้วย print()

print() สั่งให้แสดงค่าออกทางหน้าจอ ข้อความต้องอยู่ในเครื่องหมายคำพูด " " หรือ ' ' ส่วนตัวเลขไม่ต้อง

ใส่หลายค่าใน print ได้โดยคั่นด้วย , Python จะเว้นวรรคให้อัตโนมัติ ส่วนบรรทัดที่ขึ้นต้นด้วย # คือ คอมเมนต์ ซึ่ง Python ไม่รัน ใช้เขียนบันทึกให้คนอ่าน

จัดรูปแบบข้อความ

✨ f-string — วิธีที่สะดวกที่สุด

ใส่ตัว f หน้าเครื่องหมายคำพูด แล้วใส่ตัวแปรใน { } ได้เลย กำหนดทศนิยมด้วย {x:.2f} (ทศนิยม 2 ตำแหน่ง) และใส่จุลภาคคั่นหลักพันด้วย {x:,.2f}

รูปแบบตัวอย่าง (x = 1234.5678)ผลลัพธ์
{x}f"{x}"1234.5678
{x:.2f}f"{x:.2f}"1234.57
{x:,.2f}f"{x:,.2f}"1,234.57
{x:.0f}f"{x:.0f}"1235
ทายก่อนรัน

🤔 ผลลัพธ์คืออะไร

พิมพ์ผลลัพธ์ที่คิดว่าจะได้ แล้วกดตรวจ จากนั้นลองรันในกล่องด้านล่างเพื่อยืนยัน

print(f"{2/3:.2f}")
2/3 = 0.6666… ปัดเป็นทศนิยม 2 ตำแหน่งได้ 0.67
print(f"{7.5:.0f}")
ปัดเป็นจำนวนเต็ม (Python ปัด .5 ไปหาเลขคู่ จึงได้ 8)
print(f"{25000:,}")
:, ใส่จุลภาคคั่นหลักพัน
print("A", "B", sep="-")
sep="-" ใช้ขีดคั่นแทนเว้นวรรค

ขึ้นต้นด้วยตัวเลข (2nd_order) · มีเว้นวรรคหรือขีด (order value, order-value) · ใช้คำสงวน เช่น if, for, class · และระวัง ตัวพิมพ์เล็ก-ใหญ่ถือเป็นคนละตัว (Weight ≠ weight)

การแปลงชนิดข้อมูล (Type conversion)

🔄 int() · float() · str()

ฟังก์ชันแปลงเป็นตัวอย่าง
int()จำนวนเต็มint("12") → 12 · int(7.9) → 7 (ตัดทศนิยมทิ้ง)
float()ทศนิยมfloat("1.75") → 1.75 · float(3) → 3.0
str()ข้อความstr(120) → "120" ใช้เมื่อจะต่อข้อความด้วย +
อ่าน Error ให้เป็น

🐞 ข้อผิดพลาดที่พบบ่อยของมือใหม่

Error ไม่ใช่เรื่องน่ากลัว Python บอกเราเสมอว่า ผิดชนิดไหน และ บรรทัดไหน ลองรันแต่ละกล่องแล้วอ่านคำอธิบายภาษาไทย จากนั้นแก้ให้รันผ่าน

ดูวิธีแก้ (กดเพื่อเปิด)
  1. weight = float(input(...)) แปลงเป็นตัวเลขก่อนคำนวณ (ข้อความคูณทศนิยมไม่ได้)
  2. มีทศนิยม ใช้ float() แทน int() หรือพิมพ์ค่าเป็นจำนวนเต็ม
  3. ชื่อตัวแปรต้องตรงทุกตัวอักษร distance_km ไม่ใช่ Distance_km
  4. ปิดเครื่องหมายคำพูดให้ครบ print("ส่งผักถึงลูกค้าแล้ว")
